# Kitty Class — How we live

An English-only interactive lesson based on textbook pages 10–11, with original kitten-themed illustrations.

## Activities

- Open-ended warm-up and discussion questions
- Reading with five sentence gaps and answer explanations
- Topic selection and reference-word practice
- Vocabulary flashcards and answer checking
- Creative writing about a dream tiny home
- Automatic browser-local answer saving, text export and printing
- Full-size illustration previews

## Run

Open `index.html` in a modern browser, or serve this directory with any static web server. No installation or build is required.

For GitHub Pages, select **Settings → Pages → Deploy from a branch**, choose the default branch and the root folder.

The textbook video and audio are not included. Warm-up answers can be completed after watching the video supplied by a teacher.

Answers are stored in the visitor's browser; no backend or account is required.

## Files

- `index.html` — layout and styling
- `app.js` — lesson content and interactions
- `art/` — four illustrations created using ImageGen
